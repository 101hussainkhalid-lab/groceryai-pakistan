# Khareedo AI

A polished three-page landing experience for a Pakistan-focused AI grocery planner.

## Pages
- Home page with hero section and feature overview
- Meal planner page with a family-friendly planning experience
- Grocery guide page with staple items and a sample shopping list

## Preview locally
Open [index.html](index.html) in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://127.0.0.1:8000/

## GitHub Pages
Once the repository is pushed to GitHub, enable Pages from the main branch root folder.
